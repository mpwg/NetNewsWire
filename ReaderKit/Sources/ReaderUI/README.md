Scene activation refreshes FreshRSS. Simultaneous windows register separate waiters on the same account-owned job; automatic refresh does not repeat within 60 seconds of success. Manual refresh starts a new job after completion and joins one already running. Cancelling a window promptly releases its waiter with CancellationError and keeps accepted account work running, including when all current windows leave. A later caller can join that job. Failure clears ownership without recording a successful debounce; the next automatic call retries.
