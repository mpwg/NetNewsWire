# I: source-bound facts and staged consolidation — 2026-10-26

Status: **candidate; runtime acceptance pending**. The owner chose multiple stages with consolidation on 2026-10-26. The implementation replaces independent per-chunk summary concatenation. No OCR, image analysis, new UI method or external AI provider is added.

## Implemented flow

1. Split each original's title/text at Swift character boundaries until its complete JSON prompt fits the current model's context budget. Native tokenizer counts include the actual JSON format. Both stages reserve 2,000 tokens for response/schema overhead; response limits remain 1,200 tokens.
2. Ask a fresh structured LanguageModelSession for one to eight verbatim excerpts per fragment. Reader rejects empty, fabricated or reformatted excerpts. Only outer whitespace is trimmed. Reader assigns original source identities; the model does not assign provenance in this phase. Matching excerpt text merges its source sets while retaining every original identity.
3. Consolidate at most 32 evidence packets per request into at most four thematic groups. Every packet must be referenced. Numbers must occur in each group's referenced evidence; packet indices and unrelated sources cannot justify a claim. Generated HTTP(S) links and blank content remain rejected. The target language applies to consolidation; extraction copies the original language verbatim.
4. If evidence needs several requests, consolidate their results again. Each reduction must decrease the number of batches, or keep that count while decreasing actual total prompt tokens. Eight rounds bound the work. Failure to reduce returns an error; no partial AI sections escape. DigestCoordinator can retain an explicitly warned originals-only card, as before.
5. Check cancellation and live cloud permission before every request, and cancellation again after every response. No model tools can mutate app state. PCC remains disabled without the approved entitlement/provisioning and explicit per-feed consent.

The digest fingerprint now includes the source-facts/consolidation policy version. A valid cache from the previous generator is regenerated on the next generation request even when source content is unchanged. Stored digests are not deleted and no database schema migration is introduced. Opening content and generation still create no read-status/outbox writes.

Verbatim excerpts prove correspondence with supplied text, not world truth or semantic entailment of the final prose. Numeric/source/link checks are structural safeguards. Real German-offer, long-text and editorial quality still require actual model evidence on this changed generator; previous journals retain their earlier fingerprints.
