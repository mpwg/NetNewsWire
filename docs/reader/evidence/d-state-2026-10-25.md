## Reproduction and repair

The generic reload catch previously checked only the query generation. An already-running store call that ignores caller cancellation can throw an ordinary server error later. If cancellation occurs, or the search identity changes before its new SwiftUI task starts, the generation can still match and the old error becomes visible.
