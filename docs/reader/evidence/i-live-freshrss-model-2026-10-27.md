# Local model on a real FreshRSS text sample — 2026-10-27

The owner's isolated test account temporarily subscribed to the public Preisjäger feed through the shipping FreshRSS client and an in-memory ReaderStore. A preflight verified an empty persistent outbox and no existing subscription. Of the 30 fetched articles, the first two by ascending FreshRSS remote ID were fixed before inference. Their title and stored text were copied with synthetic identities, no account identifier, no source URL and a fixed arrival date into an owner-only local directory. No linked page was fetched. The temporary subscription was removed; independent refresh confirmed the baseline feed/folder sets and original read/starred states, and the verification outbox was empty. The persistent application store was not written.

Xcode MCP invoked the shipping `AppleSummaryGenerator` once on these two texts on My Mac, macOS 27.2 / 26B123, locale `en_AT`, with PCC and cloud permission disabled. The on-device model returned one section in 17.63 seconds, covering one of two source identities. The result includes the selected offer's price and coupon. It retains a German title in the English-locale output, omits the source's included-shipping detail in the free summary and renders a near-new condition with wording that can be read as new. Two source excerpts total 2,388 characters, so this result does not meet the compact-facts criterion. These are observations from one small sample, not a representative quality estimate or a second successful model review.

A separate Xcode MCP diagnostic replayed the **saved** model sections without calling a model or network, through the shipping DigestCoordinator and an in-memory store populated with the captured texts and synthetic keys. It retained both original keys in the digest and section references, added an originals-only fallback and warning for the omitted source, and left stored articles and outbox unchanged. This does not prove actual app links, rendering, full-text extraction, live model execution inside the coordinator, or behavior on other devices. Selection of key statements permits omission of an article from model prose, but the application must still link every original; this replay proves the structural reference and warning boundary only.
